# hpclang documentation

The documentation tree is intentionally small. It describes the supported
architecture and current project state, not the sequence of experiments that
led there.

- [Architecture](architecture.md) — project boundaries, runtime layers and build model.
- [Application ABI](abi.md) — the stable hpclang v1 application contract.
- [Targets](targets.md) — calculator families, model IDs and validation status.
- [Validation](validation.md) — CI gates, evidence and hardware validation.
- [Roadmap](ROADMAP.md) — milestones and current implementation order.
- [History](history.md) — HPGCC lineage and the compatibility facts retained by hpclang.
- [Licensing](licensing.md) — rules for historical code and independent reimplementation.

Historical source dumps, one-off compiler experiments and archaeology belong
under `research/`, not under `docs/`.
