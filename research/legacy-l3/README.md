# Legacy Launcher V3 bootstrap

This directory preserves the clean HP39 Launcher V3/MMU experiment that proved
stock Clang and LLD could replace the historical GCC target toolchain.

It is research evidence, not a supported hpclang execution mode.

The production architecture is HPC1 + the unified fixed-virtual hpclang v1 ABI.
No current target profile or CI workflow consumes the files in this directory.
